# Сроки партнёрских предложений

Импорт вычисляет `ends_at` от `document.generatedAt`, по времени Москвы.
Исходная дата файла сохраняется в снимке (`raw_json._cashflowGeneratedAt`).
Граница окончания исключительная: предложение активно, только пока
`starts_at <= now < ends_at`; отсутствующая граница не ограничивает период.

- «Последний день», «сегодня»: полночь после дня файла.
- «Ещё N дней»: полночь через N календарных дней от дня файла.
- Дата без времени, включая `endDate`: действует до конца указанного дня.
- ISO-дата со временем: сохраняется указанный момент; без часового пояса — Москва.
- Дата в подписи без года: год файла, без переноса истёкшей даты на следующий год.
- Нераспознанный срок: `ends_at=null`, интерфейс показывает «Срок неизвестен».

API `GET /api/partner-offers` по умолчанию исключает истёкшие и ещё не начавшиеся
предложения. `active_only=false` отключает проверку периода. Фильтр доступности
банка независим: `include_unavailable=true` включает отсутствующие у банка записи.
Пагинация `limit` (1–100), `offset` применяется после фильтров, `total` учитывает
фильтры. Приложение всегда запрашивает активные записи и дополнительно проверяет
кэш; пересчитывает отображение раз в минуту. Просмотр просроченных в UI отсутствует.

## Старые импорты

Из каталога `backend`, с явно выбранной базой в `CASHFLOW_DATABASE_URL`:

```powershell
uv run flask --app main repair-partner-deadlines
uv run flask --app main repair-partner-deadlines --apply
```

Первый вызов только показывает количество изменений; второй сохраняет их.
Предложения и персональные оценки не удаляются. Команда повторяемая.
Для старых снимков без даты файла используется сохранённая дата сбора,
что отдельно отражается в счётчике и `validity_precision=inferred`.
Дата сбора могла обновляться повторными импортами: восстановление тогда
приблизительное. Новый импорт исходного файла восстанавливает срок надёжнее.
Удалять каталог для этого не требуется. Команда не запускается автоматически.
Изменение production требует явного запроса пользователя согласно AGENTS.md.
