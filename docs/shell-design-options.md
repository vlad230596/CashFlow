# CashFlow — варианты общей оболочки

Статус: вариант A выбран как основа 17 сентября 2026 года. Отдельное представление «По картам» отклонено как дублирующее; расширенная работа по картам относится к разделу «План». Здесь фиксируется информационная архитектура, а не окончательные цвета или оформление компонентов.

## Принятое решение

- Основная оболочка следует варианту A «Задачи».
- Раздел «Выгода» содержит один основной список категорий и сравнивает доступные карты внутри каждой категории.
- Раздел «План» служит расширенным представлением по картам: показывает распределение категорий, покрытие, дубли и свободные слоты.
- Списки категорий должны быть плотнее концептуального изображения варианта A.
- На типичном телефоне высотой около 800–850 px ориентир — примерно 6–7 видимых категорий после компактной шапки вместо 4 крупных карточек.
- Повышение плотности достигается сокращением внутренних отступов, компактной строковой компоновкой и прогрессивным раскрытием условий, а не уменьшением текста и областей нажатия ниже доступных размеров.

## Общие правила для всех вариантов

- Компоновка зависит от доступной ширины окна, а не от типа устройства.
- Компактный режим: `< 600 px`; средний: `600–839 px`; широкий: `≥ 840 px`.
- Выбранный раздел, фильтры, поиск, прокрутка и незавершённый ввод сохраняются при изменении размера окна.
- На телефоне используется не более четырёх основных пунктов навигации.
- Администрирование, импорт, адрес сервера и другие редкие действия не конкурируют с повседневными задачами.
- На широком экране списки не растягиваются на всю ширину: используется ограниченный контейнер, сетка или master-detail.
- Все основные действия доступны через touch; мышь, hover и клавиатура служат ускорителями.
- Участник всегда понимает, в каком семейном пространстве он находится и какие карты ему доступны.

## Вариант A — «Задачи»

Рекомендуемый вариант для следующей версии.

Навигация строится вокруг того, зачем участник открыл приложение, а не вокруг таблиц данных.

### Телефон

```text
┌─────────────────────────────┐
│ Семья Ивановых ▾       avatar│
│ Выгода                 поиск │
├─────────────────────────────┤
│                             │
│     содержимое раздела      │
│                             │
├─────────────────────────────┤
│ Выгода │ План │ Акции │ Ещё │
└─────────────────────────────┘
```

Основные разделы:

1. **Выгода** — быстрый поиск активного кешбэка и сравнение доступных карт внутри категории.
2. **План** — расширенный обзор по картам, выбор категорий на месяц и подтверждение в банках.
3. **Акции** — партнёрские предложения.
4. **Ещё** — импорт, обновление, семейные участники, справочники, MCC, настройки и выход с учётом роли.

Для списка «Выгода» используется компактная строка: иконка категории, название и карта образуют основной слой, процент остаётся заметным справа, а срок, лимиты и полные условия раскрываются по запросу. Вся строка остаётся одной крупной областью нажатия; небольшие бейджи не превращаются в отдельные тесные кнопки.

### Средний и широкий экран

```text
┌──────────────┬─────────────────────────────────────┐
│ CashFlow     │ Семья Ивановых ▾          профиль  │
│              ├─────────────────────────────────────┤
│ ● Выгода     │                                     │
│   План       │       рабочая область               │
│   Акции      │       max-width / master-detail     │
│              │                                     │
│ ──────────── │                                     │
│   Управление │                                     │
│   Настройки  │                                     │
└──────────────┴─────────────────────────────────────┘
```

В среднем режиме боковая панель может сворачиваться до иконок. На широком экране она показывает подписи и отделяет повседневные разделы от управления.

### Сильные стороны

- наиболее короткий путь к ответу «какой картой платить»;
- сокращает четыре похожие вкладки до трёх понятных задач без дополнительного режима внутри «Выгоды»;
- административные действия перестают перегружать AppBar;
- хорошо работает уже с текущими данными;
- естественно расширяется семейным переключателем и правами доступа.

### Компромисс

Раздел «Карты» перестаёт быть самостоятельным пунктом. Быстрое сравнение остаётся в «Выгоде», а расширенная работа по картам переносится в «План».

## Вариант B — «Карты и данные»

Навигация сохраняет текущую объектную модель и делает карту главным способом входа в данные.

### Телефон

```text
┌─────────────────────────────┐
│ Карты семьи            avatar│
├─────────────────────────────┤
│                             │
│      карточки банков        │
│      и их категории         │
│                             │
├─────────────────────────────┤
│ Карты │ Категории │ План │ Акции │
└─────────────────────────────┘
```

Основные разделы:

1. **Карты** — семейный набор карт и выгоды по каждой карте.
2. **Категории** — общий поиск активного кешбэка.
3. **План** — выбор категорий на месяц.
4. **Акции** — партнёрские предложения.

Настройки и управление открываются из профиля или бокового drawer.

### Широкий экран

Постоянная боковая навигация сохраняет четыре раздела. Сетка карт используется как основная рабочая область, а выбранная карта может открываться в правой панели.

### Сильные стороны

- минимально меняет существующую ментальную модель;
- явно показывает, кому и какому банку принадлежит каждая карта;
- удобен, если участники обычно начинают выбор именно с известной карты.

### Компромиссы

- «Карты» и «Категории» остаются двумя представлениями почти одних данных;
- четыре основных пункта полностью занимают мобильную навигацию;
- семейные функции и настройки приходится прятать глубже;
- задача «какой картой платить» иногда требует лишнего перехода.

## Вариант C — «Семейный центр»

Навигация строится вокруг общей домашней страницы и лучше всего готовит продукт к нескольким аккаунтам.

### Телефон

```text
┌─────────────────────────────┐
│ Добрый вечер, Анна     avatar│
│ Семья Ивановых ▾             │
├─────────────────────────────┤
│ [ Найти категорию или банк ] │
│                              │
│ План месяца       8 из 12    │
│ Непокрыто: 3 · Дубли: 1      │
│                              │
│ Доступные карты              │
│ Предложения истекают скоро   │
├─────────────────────────────┤
│ Главная │ План │ Акции │ Ещё │
└─────────────────────────────┘
```

Основные разделы:

1. **Главная** — быстрый поиск, статус плана, доступные карты и срочные предложения.
2. **План** — подробное планирование месяца.
3. **Акции** — партнёрские предложения.
4. **Ещё** — семья, управление и настройки.

### Широкий экран

Главная становится компактной панелью из двух или трёх колонок: поиск и основные выгоды, статус месячного плана, семейные карты и срочные предложения. Остальные разделы используют боковую навигацию и master-detail.

### Сильные стороны

- лучше всего показывает CashFlow как семейный продукт;
- даёт место для совместного статуса и будущих уведомлений об изменениях;
- хорошо масштабируется на семейное пространство, приглашения и разные права;
- позволяет вынести самое важное из нескольких разделов на один экран.

### Компромиссы

- требует нового агрегирующего экрана и правил приоритизации блоков;
- часть показателей пока придётся вычислять только на клиенте;
- есть риск превратить главную в перегруженный dashboard;
- быстрый поиск получает дополнительный навигационный уровень, если не оставить его постоянно доступным.

| Критерий | A — Задачи | B — Карты и данные | C — Семейный центр |

| Близость к текущему UI | Средняя | Лучшая | Низкая |
| Простота телефона | Лучшая | Средняя | Хорошая |
| Использование desktop | Хорошее | Хорошее | Лучшее |

| Риск перегрузки | Низкий | Средний | Высокий |

## Рекомендация

Для текущего этапа выбрать **вариант A «Задачи»**. Он улучшает главные существующие сценарии без зависимости от ещё не реализованной семейной модели. При этом верхний переключатель семейного пространства и раздел управления можно добавить позже без перестройки основной навигации.

Полезные элементы варианта C — статус семейного плана и срочные предложения — можно со временем добавить в верхнюю часть «Выгоды», не создавая отдельную главную страницу.

## Визуальное направление после выбора оболочки

Рекомендуемая отправная точка — спокойный функциональный fintech:

- светлые нейтральные поверхности и высокий контраст;
- тёмный сине-графитовый основной цвет;
- один тёплый акцент для самого важного действия или выгоды;
- умеренная плотность, увеличиваемая на desktop;
- минимальные тени, ясные границы и единый набор Material Symbols;
- движение только для объяснения смены состояния, без декоративных анимаций.

Точную палитру, типографику и форму компонентов следует выбирать отдельно после утверждения информационной архитектуры. До выбора дизайн-система не сохраняется как окончательная.
