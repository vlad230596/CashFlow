# «План» — полностью ручной режим первой версии

Статус: утверждённое направление первой версии. Визуальные детали макетов ещё могут уточняться. Мобильный макет: [plan-manual-mobile.png](design/concepts/plan-manual-mobile.png). Компьютерный макет: [plan-manual-desktop.png](design/concepts/plan-manual-desktop.png).

## Принцип

Пользователь самостоятельно выбирает потребность и назначает ей одну из доступных карт. Приложение не рекомендует лучший вариант и не перераспределяет категории автоматически.

Приложение помогает только проверяемыми фактами:

- показывает процент, свободные места и известные ограничения;
- считает покрытие потребностей и заполненность карт;
- предупреждает о незакрытых потребностях, дублях и переполнении;
- группирует итоговый план по картам для последующего подтверждения в банках.

Семь приоритетов остаются чек-листом качества, а не автоматическим конвейером. Пользователь может проходить их в любом порядке.

## Адаптивная структура

На компактной ширине используется последовательный master-detail сценарий:

1. список потребностей;
2. отдельный экран выбора карты для одной потребности;
3. итоговый план по картам.

На расширенной ширине те же данные одновременно находятся в трёх колонках: потребности, ручное назначение, текущий план. При изменении ширины выбранная потребность и несохранённый выбор карты не должны сбрасываться.

## Что можно добавить позже

Автоматические подсказки могут появляться постепенно как необязательный слой поверх ручного режима: сначала сортировка, затем простые предупреждения, позднее — объяснимые предложения. Ручное назначение при этом остаётся доступным всегда.
