07 · Роли в интерфейсе

visibility follows server authority
ROLE BEHAVIOUR · REFERENCE

Viewer

  • читает продуктовые данные
  • не видит mutation CTA
  • получает 403 view по admin deep link

Editor

  • всё, что viewer
  • меняет категории кешбэка
  • запускает существующий импорт

Admin

  • всё, что editor
  • CRUD банков, участников, карт
  • MCC и аккаунты доступа
UI не заменяет server authorization: 401 очищает сессию, 403 сохраняет её и показывает безопасный recovery path.
