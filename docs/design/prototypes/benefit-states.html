Нельзя выбрать один лучший вариант

Для наблюдавшихся MCC лидируют разные карты. Выберите известный код только если он подтверждён для этой покупки.

MCC 59455 наблюдений

Карта •1234вариант для этой ветви
MCC 56412 наблюдения
Магазин→5641→Категория B
Карта •5678вариант для этой ветви

Почему ответ неопределённый

Профиль продавца — история наблюдений, а не гарантия будущего MCC. При сужении окна этот detail становится compact-экраном; запрос, выбранный магазин и позиция списка сохраняются.

Master-detail не создаёт новый маршрут: это адаптивное представление того же query/result state. Слева остаётся контекст поиска, справа — ответ и объяснение.
