# Каталог кешбэка ВТБ Онлайн

Нужный каталог находится в авторизованном ВТБ Онлайн по адресу `https://online.sbpvtb.ru/products/cashback/catalogue` (переход с `https://online.sbpvtb.ru/products/cashback` через «Все акции»). Это предложения магазинов и сервисов внутри банка, не ВТБ Шопинг.

Исследовательский сборщик `app/scripts/collect_vtb_cashback_catalogue.mjs` подключается к вкладке Chrome через DevTools Protocol на порту `9223`, обновляет каталог и читает ответ ВТБ с категориями и предложениями. Из каталога сохраняются название категории, её изображение и список предложений. Для каждого предложения сохраняются магазин, ставка, полный текст страницы условий, ссылки «Подробная информация» и «Перейти к покупкам», категории, иконка и большое изображение страницы условий. Повторяющиеся в разных категориях предложения объединяются по коду с сохранением всех категорий; если данные дублей различаются, сборщик останавливается с ошибкой.

Запуск из каталога `app` после входа в ВТБ Онлайн:

```powershell
node scripts/collect_vtb_cashback_catalogue.mjs
```

Результат: игнорируемый Git снимок `app/.local/vtb-cashback-catalogue.json` и файлы `app/.local/vtb-cashback-images/`. При повторном запуске неизменившиеся изображения используются из уже сохранённых файлов. Скачивание изображений выполняет общий модуль `app/scripts/lib/save-offer-icon.mjs`.

На 14 сентября 2026 года собрано 17 категорий и 122 уникальных предложения (135 вхождений в категории). У всех 122 предложений есть текст условий, ссылка на правила и локальная иконка. Сохранены также 17 изображений категорий и 121 большое изображение предложения. У «Магнит Плюс Премиум» большое изображение в ответе ВТБ отсутствует; ошибки скачивания нет. Итого в каталоге изображений 260 файлов.

Ссылки на документы с правилами сохранены, но содержимое PDF не извлекалось. Снимок зависит от даты и содержимого каталога банка. Скрипт ничего не подключает и не нажимает «Перейти к покупкам»; в расширение он пока не перенесён.
