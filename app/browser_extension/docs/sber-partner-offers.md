# Партнёрские предложения СберСпасибо

Исследовательский сборщик: `app/scripts/collect_sber_partner_offers.mjs`. Он подключается к авторизованной вкладке СберБанк Онлайн через Chrome DevTools Protocol (по умолчанию порт `9223`). Запуск из `app`:

```powershell
node scripts/collect_sber_partner_offers.mjs
```

Результат сохраняется в игнорируемый Git файл `app/.local/sber-partner-offers.json`. Сборщик не получает пароли или cookies и не выбирает банковские категории. Данные привязаны к текущему кабинету, региону выдачи сайта и времени сбора; перед публикацией их нужно проверить.

Срез от 14 сентября 2026 года: в разделе «Партнёры и акции» после раскрытия всех блоков показаны 84 карточки с начислением бонусов, соответствующие 80 уникальным партнёрам. Четыре партнёра повторяются в каталоге; их появления сохранены в `appearances`. Отдельный раздел «Акции» содержит 6 предложений, они сохранены в `promotions`. Каталог партнёров открыт с фильтром «Накопить»; предложения только для траты бонусов в этот снимок не входят.

Для каждого партнёра сохранены ID, название, категория на странице партнёра, текст карточки, полная страница условий, внешние ссылки и ссылки на правила. Кнопка «Показать ещё» раскрывает дополнительные ставки, «Показать все» — полный текст ограничений, а «Показать подробнее» — условия конкретной ставки. Тексты этих окон сохранены отдельно в `fullConditions` и `rateDetails`. У акций сохранены отдельные карточки и страницы деталей. Тексты PDF-документов по ссылкам не разбирались.

Сборщик использует обычные ссылки и элементы интерфейса СберСпасибо; при изменении разметки сайта селекторы нужно перепроверить. Он выполняет только чтение и сохранение локального снимка. В расширение браузера код пока не перенесён.
