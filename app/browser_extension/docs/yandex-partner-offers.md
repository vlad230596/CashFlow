# Партнёрский кешбэк Яндекс Пэй

Сборщик `app/scripts/collect_yandex_partner_offers.mjs` читает страницу `https://bank.yandex.ru/webview-sdk/partners/cashback`, которая открывается из блока «Больше кешбэка от партнёров» в «Свои Плюсы» (`https://sp.yandex.ru/cashback/current`).

Запуск из каталога `app`, когда страница партнёров открыта в Chrome с DevTools Protocol на порту `9223`:

```powershell
node scripts/collect_yandex_partner_offers.mjs
```

Сборщик сохраняет в игнорируемый Git файл `app/.local/yandex-partner-offers.json` название партнёра, ставку в процентах, видимое описание предложения, ссылку Яндекс Банка для перехода к партнёру, адрес магазина, адреса и локальные пути иконки и большого изображения карточки. Из страницы «Свои Плюсы» дополнительно берутся текст общего ограничения и ссылка на правила программы. Изображения лежат в `app/.local/yandex-partner-images/`; при повторном запуске неизменившиеся файлы не скачиваются снова. Скачивание выполняет общий модуль `app/scripts/lib/save-offer-icon.mjs`.

На 14 сентября 2026 года на странице видно 22 предложения. У каждого сохранены иконка и большое изображение, всего 44 файла. Страница «Свои Плюсы» указывает общий предел 10 000 баллов Плюса за месяц и начисление в течение 21 дня; ссылка на [правила Яндекс Пэй](https://yandex.ru/legal/card_and_pay_points/) сохранена в снимке. Отдельных страниц подробных условий для 22 карточек каталог не показывает: поверх карточки находится прямая ссылка перехода к партнёру. Поэтому условия отдельных предложений ограничены тем текстом, который показывает каталог. Переход в магазин следует выполнять через исходную ссылку Яндекса; прямой адрес магазина в снимке нужен для идентификации партнёра и сам по себе не гарантирует начисление кешбэка.

Сборщик только читает страницу и скачивает изображения. Он не открывает магазины и не подключает услуги или акции. Пока это отдельный исследовательский скрипт, не часть расширения.
