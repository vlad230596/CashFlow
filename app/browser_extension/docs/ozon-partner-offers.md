# Партнёрский кэшбэк Ozon Банка

Исследовательский сборщик: `app/scripts/collect_ozon_partner_offers.mjs`. Он подключается к авторизованной вкладке Ozon Банка через Chrome DevTools Protocol (порт `9223`) и открывает каталог `https://finance.ozon.ru/lk/promotions?filter=all`. Запуск из `app`:

```powershell
node scripts/collect_ozon_partner_offers.mjs
```

Результат — игнорируемый Git файл `app/.local/ozon-partner-offers.json`. Снимок привязан к текущему кабинету и времени сбора. Данные включают ставку, категорию, срок, текст получения кэшбэка, лимиты, исключения, описание партнёра, ссылки на документы и статус подключения. Сборщик сверяет число карточек со счётчиком вкладки «Все» и сохраняет снимок после каждой карточки, чтобы повторный запуск продолжал работу.

**Открытие неподключённой карточки на этом сайте автоматически подключает акцию.** Текущий сбор был выполнен с разрешения пользователя; на 14 сентября 2026 года собрано 56 из 56 предложений, и банк показывает 56 подключённых. Для будущих новых предложений сборщик по умолчанию остановится перед открытием неподключённой карточки. Чтобы разрешить подключение, запустите:

```powershell
node scripts/collect_ozon_partner_offers.mjs --allow-connect
```

В каталоге показано 17 тематических групп и кнопка «Все акции». У всех 56 предложений сохранены уникальный `alias` страницы и текст условий; 46 карточек содержат внешние ссылки на дополнительные документы. Содержимое документов по ссылкам не разбиралось. Код пока остаётся отдельным исследовательским сборщиком и не перенесён в расширение.
