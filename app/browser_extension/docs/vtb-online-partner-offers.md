# Партнёрские предложения ВТБ Онлайн

Сборщик `app/scripts/collect_vtb_online_partner_offers.mjs` читает раздел «Выгода» в авторизованной вкладке ВТБ Онлайн через Chrome DevTools Protocol (порт `9223`). Он сохраняет карточки блока «От партнеров ВТБ» и предложение Яндекс Путешествий из блока «Еще больше выгоды». ВТБ Шопинг в сбор не входит.

Запуск из каталога `app`:

```powershell
node scripts/collect_vtb_online_partner_offers.mjs
```

Результат — игнорируемые Git файлы `app/.local/vtb-online-partner-offers.json` и `app/.local/vtb-online-partner-icons/`. У каждой карточки есть название, подпись, полный текст открываемой панели условий, адрес исходного изображения и путь к сохранённой копии. Загрузчик изображений находится в `app/scripts/lib/save-offer-icon.mjs` и поддерживает URL, SVG и data URL. При сбое системного DNS можно запустить сбор с `OFFER_ICON_PUBLIC_DNS=1`: тогда изображения скачиваются через публичный DNS без изменения настроек Windows.

На 14 сентября 2026 года в ВТБ Онлайн обнаружены 3 карточки «От партнеров ВТБ»: спецпредложения за уровень «Золото», бесплатный ВТБ Мобайл и кешбэк «Магнита». Также видна карточка «Кешбэк 12% на отели» от ВТБ и Яндекс Путешествий. Сохранены изображения всех 4 карточек. Для «Магнита» указано: заказы в Магнит Доставке или Магнит Косметик через ВТБ Онлайн, 10% на первые 20 000 ₽, затем 5% на каждую покупку; требуется выполнить 2 из 3 действий в течение месяца. Карточка отелей не раскрывает дополнительные условия в веб-кабинете, поэтому её `detailsText` остаётся `null`.

Снимок зависит от кабинета и даты. Скрипт открывает только информационные панели и не подключает услуги или акции. Пока это отдельный исследовательский сборщик, не часть расширения.
