# Обновить партнёрские предложения — 16 сентября 2026

Задача: собрать актуальные индивидуальные и партнёрские предложения Т-Банка,
Альфа-Банка, Сбера, Ozon Банка, Яндекс Пэй и ВТБ через Chrome-расширение.
Сохранить название, иконку, описание, исходную подпись ставки, банк и дату сбора.
Базу данных на этом этапе не использовать.

Свежий сбор запущен из текущей панели расширения. Банки на странице входа
потребуют авторизации владельца. Панель должна оставаться открытой до завершения.

Из каталога `app/`:

```powershell
# Начать новый сбор в открытом расширении:
node scripts/refresh_partner_offers.mjs --start
# Проверить прогресс и сохранить текущую историю расширения:
node scripts/refresh_partner_offers.mjs
# Подготовить файл и локальные иконки для экспериментальной вкладки:
node scripts/build_partner_offers_preview.mjs
```

Результат расширения сохраняется в `.local/extension-partner-offers.json`.
Просмотр приложения использует `assets/partner_offers/offers.json` и
`assets/partner_offers/icons/`. После обновления требуется перезапуск/пересборка
приложения, чтобы обновить Flutter assets.

Более свежие выгрузки имеют приоритет над старыми `.local/*partner-offers.json`.
Старые предложения остаются для демонстрации полноты ранее собранных данных;
это смешанный снимок, а не гарантированно актуальный каталог. Дата сбора видна
в карточке. Не считать отсутствие ставки нулевым кешбэком и сохранять «до», «от»,
«скидка» и бонусные ставки в исходной подписи.

Критерий завершения задачи сбора: для каждого банка есть свежий результат
с количеством предложений либо зафиксированная причина невозможности сбора;
файл просмотра пересобран. Не выдавать старую выгрузку за свежую.

## Сроки, ограничения и логотипы в экспериментальной вкладке

Файл просмотра сохраняет `validityLabel`, `startDate`, `endDate`, `limits`,
`requirements` и полный текст `conditions`. Денежные и бонусные лимиты
сохраняются в исходных единицах, включая ограничения на покупку и месяц.
Если подробности отсутствуют в новом снимке, доступные старые условия
помечаются `conditionsFromHistory` и датой `conditionsCollectedAt`.
Отсутствующие сроки или лимиты не означают бессрочную/неограниченную акцию.

Логотипы Сбера и Ozon сохранены в локальные Flutter assets. Ozon использует
CSS-фон `.card-body .logo .image`, который теперь читает и расширение.
Для обновления локальных иконок откройте каталог Ozon в Chrome, затем из `app/`:

```powershell
node scripts/build_partner_offers_preview.mjs
node scripts/collect_partner_offer_icons.mjs
node scripts/build_partner_offers_preview.mjs
```

Кеш иконок: `.local/partner-offer-icons.json` и `.local/preview-offer-icons/`.
Иконки Сбера при проблеме с сертификатом Node читаются как публичные ресурсы
через уже открытый Chrome, без передачи cookies. Для просмотра карточкам
не требуется загружать эти логотипы с банковских CDN.
