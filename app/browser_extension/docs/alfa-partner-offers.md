# Партнёрские предложения Альфа-Банка

Исследовательский сборщик: `app/scripts/collect_alfa_partner_offers.mjs`. Он подключается к уже авторизованной вкладке `https://web.alfabank.ru/partner-offers/` через Chrome DevTools Protocol (по умолчанию порт `9223`). Запуск из `app`:

```powershell
node scripts/collect_alfa_partner_offers.mjs
```

Результат сохраняется в игнорируемый Git файл `app/.local/alfa-partner-offers.json`. Файл привязан к текущему кабинету и времени сбора; не публиковать его без проверки. Сборщик проходит категории в модальном каталоге, сохраняет каждую категорию и сверяет число карточек со счётчиком банка. Предложения с одинаковым `offerId` объединяются, но все их категории сохраняются. После каждой категории файл перезаписывается, поэтому повторный запуск продолжает сбор и дополняет отсутствующие ссылки на правила.

Срез от 14 сентября 2026 года: 18 разделов, 55 уникальных предложений, в том числе 54 кэшбэка и одна скидка. Для всех 55 сохранены детали карточки: ставка, способ оплаты, срок, шаги, текст условий, описание партнёра. Для 54 кэшбэков сохранена ссылка на PDF «Правила акции»; у скидки ЦУМ такой кнопки нет. Отдельная акция «Вкусно — и точка» использует особый шаблон без обычного заголовка, но её прогрессия 0/10/30/50/100%, порог покупки, лимит и исключения находятся в `details.terms` и `details.steps`.

`offerId` и `rulesUrl` извлекаются из свойств React-компонентов, потому что в DOM карточки этих значений нет. Это зависит от текущей реализации сайта банка и требует проверки после изменений интерфейса. PDF-файлы по ссылкам не разбирались: текст карточки и ссылка на официальный документ сохранены раздельно. Скрипт не переносился в расширение браузера; это отдельный исследовательский сборщик.
