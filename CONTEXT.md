# CashFlow: кешбэк и партнёрские предложения

Термины для категорий кешбэка и персонального каталога банковских предложений.
Описание реализации и требований находится в [ТЗ партнёрских предложений](docs/partner-offers-spec.md).

## Language

**Категория кешбэка**:
Категория расходов, для которой банк задаёт правила начисления кешбэка, в том числе выбор на месяц.
_Avoid_: Партнёрское предложение, акция магазина.

**Партнёрское предложение**:
Предложение банка для покупок у определённого партнёра: кешбэк, скидка или иная выгода с собственными условиями.
_Avoid_: Категория кешбэка, гарантированный кешбэк.

**Снимок предложения**:
Сведения о предложении, прочитанные в определённый момент из банковского источника.
_Avoid_: Новое предложение при каждом повторном сборе.

**Стабильное предложение**:
Логическая акция конкретного банковского профиля, которая сохраняет личные оценки при появлении новых снимков условий.
_Avoid_: Снимок предложения, похожая акция по совпадению названия.

**Запуск импорта**:
Один результат чтения каталога партнёрских предложений для конкретного банковского профиля с явно известной или неизвестной полнотой.
_Avoid_: Гарантия исчезновения отсутствующих предложений при частичном чтении.

**Владелец банковского профиля**:
Человек, из банковского кабинета которого получены персональные предложения; может владеть несколькими картами.
_Avoid_: Пользователь авторизации без уточнения роли.

**Пользователь приложения**:
Человек, авторизованный в CashFlow и задающий собственную оценку интереса к предложениям.
_Avoid_: Владелец карты без уточнения роли.

**Оценка интереса**:
Личная классификация предложения как интересного, отложенного или скрытого.
_Avoid_: Процент кешбэка, подтверждение или подключение акции в банке.

**Отложенное предложение**:
Предложение, которое сейчас не представляет очевидного интереса, но может пригодиться при других обстоятельствах.
_Avoid_: Чёрный список, удалённое предложение.

**Чёрный список**:
Постоянное решение пользователя скрывать заданное предложение или выбранную группу предложений до явного восстановления.
_Avoid_: Истёкшее предложение, временный фильтр.

**Область скрытия**:
Явно выбранная цель чёрного списка: предложение, семейство акций или партнёр в заданных банках.
_Avoid_: Неявное объединение по похожему названию партнёра.
